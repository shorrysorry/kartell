# 02. 회원 인증 및 권한

## 인증 방향
기존 이름+아이디만 로그인하는 안 대신 카카오 소셜 로그인 단일 방식으로 진행하는 방향. 가입과 로그인 버튼을 통합한다. 카카오 계정 인증은 실제 모임원 자격 확인과 별개다. 자체 아이디 중복 체크, 비밀번호, 이메일/전화번호 수집은 최신 안에서 제외.

신규 카카오 인증 → 이름(필수, 모임에서 사용하는 이름) / 프로필 이미지(선택, 동의한 카카오 프로필 또는 직접 등록) → 가입 신청 → PENDING → 관리자 승인 → ACTIVE.
기존 인증 → 서버에서 회원 상태 검증 → ACTIVE만 서비스 접근. 대기/거절/정지/탈퇴 상태별 안내. 자동 로그인 세션은 서버의 권한 확인을 대체하지 않는다.

## 회원 상태 설계안
| 코드 | 의미 |
|---|---|
| PENDING | 승인 대기 |
| ACTIVE | 정상 |
| REJECTED | 가입 거절 |
| SUSPENDED | 이용 정지(제안) |
| WITHDRAWN | 자진 탈퇴 |
| REMOVED | 관리자 강제 탈퇴 |

관리자 가입 승인 및 강제 탈퇴 기능은 확정. 상태 코드, 정지/복구 절차는 설계안. 강퇴 시 접근 권한 및 세션 회수, 신규 참가자 목록 제외, 푸시 중단. 기존 참가자의 성적을 왜곡하지 않도록 과거 기록은 보존하되 개인정보 삭제/익명화 정책과 카카오 연결 해제는 별도 확정. 재가입은 관리자 재승인 방향. 탈퇴 차단을 위해 불필요하게 식별자를 영구 보관하지 않는다.

## 권한 매트릭스
모든 일반 권한은 ACTIVE 전제. 기록 생성 권한과 일정 생성 권한은 독립 플래그이며 동시에 보유 가능. 관리자는 두 권한을 포함하는 설계안.
| 동작 | 일반 | 기록 권한자 | 일정 권한자 | 관리자 |
|---|---|---|---|---|
| 게임 조회, 게시판, 일정 조회/신청 | O | O | O | O |
| 참가 기록 조회 | O | O | O | O |
| 비참가 기록 조회 | X | 본인 생성 건 | 본인 생성 건(권한 변경 시 정책 검토) | O |
| 기록 생성 | X | O | X | O |
| 미확정 기록 수정/삭제/확정 | X | 본인 생성 건 | X | O |
| 확정 기록 수정/삭제 | X | X | X | O |
| 일정 생성 | X | X | O | O |
| 출석 확인 | X | X | 본인 생성 일정 | O |
| 가입 승인/강퇴/권한 관리 | X | X | X | O |
| 게임 등록/계산기 개발 | X | X | X | X |

개발자만 소스/배포로 게임을 추가. 별도 앱 내 개발자 계정 불필요. 관리자도 UI에서 게임 등록 불가.

## 권한 구현 시 유의
- 버튼 숨김뿐 아니라 API/DB/사진 접근에도 권한 검증.
- 권한 회수 후 기존 생성 건 수정/확정을 차단하는 것이 제안 정책; 미확정 건은 관리자가 처리.
- 대리 기록 생성자가 본인 건을 조회할 수 있도록 예외 인정(앞선 설계에서 명시). 개인 통계에는 참가자만 포함.
- 관리자 중요 작업에 변경 전후 상태, 처리자, 시각, 사유 감사 로그.
- 관리자 최초 부여, 마지막 관리자 보호, 계정 복구, 개인정보 처리방침, 카카오 연결 해제/재가입 세부 정책 미결.
