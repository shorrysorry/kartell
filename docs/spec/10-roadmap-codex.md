## Codex 전달용 지시문
README 및 01~10 문서를 모두 읽고 최신 확정 요구사항을 우선하라. 설계안과 미결 사항을 확정 요구사항으로 오인하지 말라. 현재 단계는 UI 프로토타입 통합 및 기획 검증이며 프로젝트 초기 세팅, 실서비스 DB, 인증 연동, 배포는 별도 요청 전 시작하지 않는다. 기존 저장소가 있는 경우 먼저 구조와 구현 현황을 확인하고, 기존 기능을 임의로 삭제하거나 덮어쓰지 않는다.

통합 UI 작업 시 Mock Data를 사용하고 권한 및 상태 전이를 검증 가능하게 구현한다. 기존 v0.2의 절제된 리스트 기반 디자인을 유지한다. 게임별 점수 계산은 개발자가 제공한 규칙을 사용하며, 제공되지 않은 실제 점수식/확장판/동점 규칙은 임의 추정하지 않는다. 개발자가 검증한 지원 게임만 기록 가능하게 한다. 임시 데이터나 예시 계산을 운영 기능으로 표시하지 않는다.

실제 개발 요청 이후에는 작은 기능 단위로 구현하고 각 변경의 테스트, 미결 사항, 권한 검증 결과를 문서에 기록한다. 보안 검증을 UI 노출 제한으로 대체하지 않는다. 회원/기록/일정 권한과 원본 기록의 보존, 활동 기반 업적의 점진적 확장 원칙을 유지한다.
