# kartell — 기획 및 개발 인수인계

기준: 2026-11-24까지의 기획 및 2026-11-26 서비스명 확정. 공식 서비스명: kartell. 실제 개발 착수 전 기획/프로토타입 단계.

## 문서 읽는 법
- **확정**: 사용자가 직접 결정한 요구사항 또는 명시적으로 선택한 정책.
- **설계안**: 앞선 대화에서 제안한 구현 방법/화면 구조. 개발 전 검토 가능.
- **미결**: 아직 결정하거나 검증하지 않은 사항. 임의로 확정하지 않는다.
- 최신 결정이 초기 초안보다 우선한다. 초기 아이디 로그인, 전체 회원 기록 공개, 관리자 게임 등록, 게임별 세부 업적 중심 방향은 폐기 또는 후순위다.

## 지금 바로 할 일
알림 정책 확정 → IA 및 MVP 최종 검토 → 통합 모바일 프로토타입 → 사용성 검증 → DB/API 상세 설계 → 실제 개발. 지금은 프로젝트 초기 세팅이나 서비스 배포를 시작하지 않는다.

## 핵심 결정 요약
단일 보드게임 모임 전용 PWA. 카카오 로그인 방향, 관리자 가입 승인 및 강제 탈퇴. 기록/일정 생성 권한은 독립적으로 부여. 기록 열람은 참가자와 생성자 및 관리자로 제한. 생성자는 미확정 기록을 수정·삭제하고 즉시 확정 가능하며 확정 후 관리자만 변경 가능. 게임과 점수 계산기는 개발자만 코드로 추가. 통계는 게임 단위, 모임 통계는 인기 게임과 최고 기록 중심. 활동 업적은 적게 시작하고 업데이트로 확장. 커뮤니티는 자유게시판과 일정관리. 일정 생성 권한자 및 관리자만 일정 생성, 생성자 및 관리자 출석 확인, 인원 제한 선택, 시작 전 참여 취소 자유.
