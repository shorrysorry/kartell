# 04. 플레이 기록 상세 명세

## 확정 입력 데이터
필수: 보드게임, 플레이 날짜, 참가자, 게임별 세부 점수, 최종 점수 및 순위(자동 산출).
선택: 확장판, 참가자별 캐릭터 및 세력, 플레이 사진, 플레이 메모.
날짜 기본값 오늘, 참가자는 승인된 회원 목록에서 선택(설계안). 캐릭터/세력은 지원 목록에서 선택. 게임별 인원수와 규칙 적용. 게스트 지원은 미결.

## 생성 흐름 설계안
1. 게임 선택: 검색, 지원 여부 확인, 확장판 조합 선택.
2. 플레이 정보: 날짜, 참가자 선택, 캐릭터/세력 설정. 생성자 참가 필수 아님.
3. 점수 입력: 게임별 전용 UI, 참가자별 입력, 실시간 합산, 누락 안내. 항목별 입력 모드는 향후 검토.
4. 결과 검토: 점수/순위/동점 정보 확인, 사진 및 메모 선택 입력.
5. 미확정 저장: 서버 저장 후 해당 참가자 및 생성자/관리자 조회 가능.
6. 상세 페이지: 생성자는 수정/삭제/확정. 확정 전 경고 및 확인 제공.
7. 확정: 생성자 단독 확정 즉시 완료, 참가자 승인 불필요. 이후 관리자만 수정/삭제.

## 상태 및 권한
| 상태 | 조회 | 수정/삭제 | 통계/업적 |
|---|---|---|---|
| 작성 중(저장 전) | 작성자 | 작성자 | 제외 |
| DRAFT | 참가자/생성자/관리자 | 생성자/관리자 | 제외(설계안) |
| CONFIRMED | 참가자/생성자/관리자 | 관리자만 | 반영(설계안) |
| DELETED | 일반 회원 제외 | 관리자 정책 | 제외 |
확정 취소/재오픈 기능은 정하지 않았으며 일반 회원에게 제공하지 않는다. 대리 기록은 생성자의 개인 성적에 반영하지 않는다.

## 저장 구조 설계안
recordId, gameId, playedOn, expansionIds, createdBy, createdAt, updatedAt, confirmedBy/At, status, scoringRuleVersion, revision, memo, photo references. 참가자별 memberId, characterId/factionId, rawScoreInputs, scoreBreakdown, totalScore, rank, outcome. 게임별 공용 입력 데이터 및 비교 조건도 필요한 경우 보존. 작성 중 로컬 임시 데이터와 서버 미확정 레코드는 분리.

## 예외 처리
- 점수 빈 값과 0을 구분, 게임 규칙에 따라 유효성 검사(음수 허용 여부도 게임별).
- 게임/확장판/참가자 변경 시 기존 데이터 손실 안내 및 확인. 뒤로 이동 시 입력 유지.
- 통신 오류/앱 종료 시 임시 보존 및 재시도. 로그아웃/탈퇴 후 민감한 캐시 삭제.
- 동시 수정/확정: revision 및 트랜잭션, 중복 요청 방지.
- 생성 권한 회수/회원 비활성화/미지원 조합: 서버 차단.
- 사진 실패 시 입력값 유지, 크기/형식 제한 및 접근 권한 검사.
- 동일 날짜/게임/참가자 중복 경고 가능(같은 날 여러 판을 막지 않음).
- 관리자 확정 수정/삭제 시 사유 및 감사 로그, 파생 데이터 재평가.
- 과거 탈퇴 회원 기록 유지 및 개인정보 정책 적용.

## 검증 시나리오
대리 생성, 다른 생성 권한자의 수정 차단, 참가자/미참가자 조회 차이, 미확정 수정/삭제, 확정 즉시 잠금, 관리자 예외, 점수 누락/동점, 사진 선택, 입력 보존, 확정 동시 요청. 상세 사진 URL이나 알림 링크로 권한 우회 불가.
