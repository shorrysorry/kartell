# 01. 서비스 정의 및 범위

## 확정 방향
- 대상: 개발자가 실제 참여 중인 단일 보드게임 모임의 회원. 불특정 다수 대상 서비스가 아니다.
- 목적: 게임별 점수 계산을 편리하게 하고, 플레이 기록을 참가자끼리 공유하며, 모임 활동과 개인 성장 경험을 축적한다.
- 핵심 가치: 한 사람이 기록하면 참가자 모두에게 반영, 게임별 공식 계산, 활동 업적을 통한 성취감.
- 플랫폼: 모바일 우선 Next.js PWA, Vercel 배포. 스토어 등록 없이 링크 공유 및 홈 화면 설치.
- 초기 수익화 계획 없음(이전 설계안). 다른 모임으로의 확장은 현재 범위 밖.

## 사용자 유형
일반 회원: 자신의 참가 기록 확인, 게임 탐색, 커뮤니티, 일정 신청, 개인 통계/업적.
기록 생성 권한자: 일반 기능 + 플레이 기록 생성 및 본인 미확정 기록 관리.
일정 생성 권한자: 일반 기능 + 일정 생성 및 자신의 일정 출석 관리.
관리자: 회원 가입 승인/거절, 탈퇴 처리, 권한 관리, 기록/일정 관리.
개발자: 게임 데이터 및 계산기 코드 관리. 앱 내부 관리자 역할과 별개.

## MVP 범위 초안 (최종 검토 필요)
> 결정 대기 항목: [10 문서 "결정 대기: IA·MVP"](10-roadmap-codex.md#결정-대기-iamvp-2026-11-26-정리) B1~B6. 결정 전 통합 프로토타입 착수 금지.

| 영역 | 초기 범위 |
|---|---|
| 인증 | 카카오 인증, 이름/선택 프로필, 승인 대기 |
| 회원 | 관리자 승인, 강제 탈퇴, 권한 부여/회수 |
| 게임 | 개발자 등록, 검색, 기본 정보, 허용된 이미지 |
| 계산 | 지원 게임 및 검증된 확장판 조합 전용 계산기 |
| 기록 | 미확정 저장, 조회, 수정/삭제/확정, 상세 점수 |
| 통계 | 개인 게임 단위, 모임 인기 게임 및 최고 기록 |
| 업적 | 소수 활동 기반 업적, 컬렉션, 대표 토큰 |
| 커뮤니티 | 자유게시판, 댓글, 좋아요, 공지(세부 제안) |
| 일정 | 일정 생성, 참여 신청/취소, 출석 관리 |
| 알림 | 앱 내부 및 Web Push(이벤트 정책 미결) |
| 관리자 | 회원/권한/기록/일정 관리, 감사 로그 |
| PWA | 설치 안내, standalone 실행, 알림 권한 |

## 제외/후순위
다중 모임, 친구 시스템, 실시간 채팅, 종합 회원 순위, 캐릭터별 분석 화면, 개별 게임 중심 세부 업적, 게임 후기/평점 시스템, 관리자용 게임 등록 또는 범용 계산기 제작기, 미지원 게임 기록, 스토어 앱 배포. 후기/평점 업적은 관련 기능 도입 후 고려.

## 디자인 방향
AI Slop 제거: 기능 중심 제목, 화이트/차콜, 리스트와 구분선, 절제된 여백, 단일 강조색, 실제 표지(권리 확인 후), 장식 슬로건/이모지/그라데이션/과한 카드/그림자 제거. 모바일에서 빠르게 입력하고 조회할 수 있는 실용 도구를 지향.
