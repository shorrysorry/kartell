# 08. 정보 구조 및 UI 프로토타입

## 최신 IA 초안 (최종 승인 전)
로그인 → 신규 프로필 설정 → 승인 대기 / 이용 제한 / 정상 회원 홈.

| 하단 메뉴 | 주요 화면 |
|---|---|
| 홈 | 주요 공지, 다가오는 일정, 최근 개인 기록, 인기 게임, 게임별 최고 기록 |
| 게임 | 게임 목록/검색, 게임 상세, 지원 확장판, 최고 기록, 권한별 기록 시작 |
| 기록 | 참가 기록, 내가 생성한 기록, 미확정 기록, 신규 생성(권한자만), 기록 상세 |
| 커뮤니티 | 자유게시판, 상세/작성/댓글, 일정 캘린더/목록/상세/생성/출석 |
| MY | 프로필, 게임 단위 개인 통계, 업적 컬렉션, 대표 토큰, 알림/설치/계정 설정 |

상단 공통 알림센터(권한 및 상태별 노출). 관리자 진입점은 관리자에게만 표시, 가입 승인/회원/권한/기록/일정/감사 로그. 개발자 게임 관리 UI는 없음. 통계 독립 탭은 커뮤니티 탭으로 교체하는 최신 제안; 모임 통계는 홈/게임 상세, 개인 통계는 MY. 홈 및 게임 상세에서 미참가 원본 기록 노출 금지.

## 디자인 시스템 v0.2 기반
배경 #FFFFFF, 기본 강조 #252B27, 본문 #171717~#222, 보조 #737373~#80807D, 구분선 #E5E5E5. Pretendard 및 시스템 폰트, 본문 14–15px, 제목 20–24px, 4px 간격 단위, radius 4–8px, Lucide 스타일 선 아이콘. 390px 모바일 기준, 다른 너비/안전 영역/키보드/접근성 대응. 버튼 터치 영역 충분히 확보. 카드 남용, 그라데이션, 이모지 표지, 과한 그림자, 감성 카피, 과도한 강조 배너를 제거. 실제 표지는 권리 확인 후 적용. 업적 토큰은 장식이 아니라 기능적 보상 시각화.

## 대화에서 제작한 UI 이력
| 버전/화면 | 포함 내용 | 한계 및 후속 반영 |
|---|---|---|
| v0.1 Board Log | 홈/게임/기록/통계/MY, 검색 및 총점 기록 | 초기 카드/녹색/이모지 디자인 폐기, 총점 입력 방식 폐기 |
| v0.2 kartell | 화이트 리스트 중심, 게임 상세, 기록 단계, 통계, 알림 설정 | 최신 디자인 기반, 데이터/권한은 가상 |
| 관리자 회원관리 v0.1 | 승인/거절/정지/강퇴/로그 | 실제 인증 없음, 복구 정책 미결 |
| v0.3 | 이름/아이디 가입, 중복 확인, 아이디 로그인 | 카카오 전환 방향으로 폐기 |
| v0.4 | 카카오 가상 로그인, 신규 프로필, 승인 대기/정상/탈퇴 분기 | 실제 OAuth 미연동 |
| v0.5 | 생성자/참가자/미참가자/관리자 전환, 미확정 및 확정 | 이후 대리 생성/미확정 삭제 허용 반영 필요 |
| v0.6 | 4단계 기록 생성, 아르낙/윙스팬 예시 계산, 사진 로컬 미리보기, 역할별 권한 | 공식 규칙 재검증, 확장판/캐릭터 비활성, 실제 DB 없음 |
| v0.7 | 업적 컬렉션, 진행도, 대표 토큰, 테스트 횟수 증가 | 게임별 업적 중심은 최신 활동 기반 방향으로 수정 |
| 활동 업적 UI | 플레이/승리/출석/게시글/댓글/후기/파티게임 예시 | 등급/실제 도입 범위 미확정 |
| v0.8 | 자유게시판 검색/작성/댓글/좋아요, 일정 캘린더/신청/취소 | 일정 생성/출석/이미지 연동 없음 |

위 화면들은 채팅에서 제공된 독립적인 가상 UI 프로토타입이며 실제 Next.js 프로젝트/소스 저장소나 운영 기능이 아니다. 이 문서 묶음에는 해당 앱 소스 자체가 포함되지 않는다.

## 통합 프로토타입 다음 작업
최신 정책을 단일 모바일 앱에 통합. Mock 회원/권한/게임/기록/게시글/일정/업적 상태를 공유하고, 역할 테스트 전환으로 화면과 권한 검증. 로그인부터 홈 진입, 기록 생성→확정→참가자 조회→통계/업적, 일정 신청→출석, 관리자 승인/강퇴/권한 회수, 알림 클릭 흐름 검증. 가상 점수 규칙을 실제 공식 규칙으로 오인하지 않도록 표시. 초기 세팅 및 DB 연결은 통합 UI 검증 이후.
